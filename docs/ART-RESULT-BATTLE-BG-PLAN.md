## 2. 统一构图 / 视角 / 风格锚点（三批共用）
- **风格**：继承大厅已落地的「夜景舞台底」——深邃靛蓝夜空 + 层叠远山剪影 + 底部雾面，Q版厚涂笔触，无硬描边。
- **视角**：平视略俯的全景舞台背景，无透视主体、无角色、无 UI 元素。
- **明度铁律**：全图 mean L ≤ 60、峰值 ≤ 130（远低于云白卡 L227）；焦点为 0，纯背景舞台，不与前景抢注意。
- **氛围色**：靛蓝 `#16243A` 主、远山 `#2B4A6F`、雾面暖琥珀微反光（中央底部，极弱）。
- **严格禁止**：文字、数字、logo、UI 边框、光束/射线/星轨/极光、圆球卡通云、水印、任何前景主体。

## 3. 逐项差异设计

### 批次 A：结算胜利主视觉 `bg/result_win.jpg`（替换 BG-04）
- 1500×2115 JPG（与占位同尺寸同名覆盖，无需重跑 manifest）。

- 与胜利版共享完全相同的远山/雾面结构，仅色调与光晕差异（保证胜负切换不割裂）。

## 4. 生成与后处理路径
1. **先出锚点**：文生图生成 `result_win` 作为风格锚点，自检明度/风格达标。
2. **图生图派生**：以锚点为 `image1`、`input_fidelity=high`，派生 `result_lose` 与 `battle_bg`；prompt 强调「保留参考图构图/光影，只改指定氛围」。5 张战斗色调同理以 `battle_bg` 为锚点派生。
3. **后处理**：Pillow 校验尺寸 1500×2115；JPG 直接覆盖；PNG 变体检查 alpha/尺寸。无需去背（背景图不透明）。
4. **水印清理**：若出图工具带水印，用右下角连通域 + inpaint（沿用大厅背景后处理手法）。
