# 石砖素材重做方案（强化立体侧面）· 待确认

> 2026-11-20。目标：在保持 OLD 饱满顶面不变的前提下，把厚度侧面做厚做实、投影加强，让「侧面轮廓明显超出六边形格子」真正可见。
> 出图消耗：每张约 5–10 credits，本方案先出 **1 张**锚点（hex_bright）验证，满意后再决定是否派生其余地块。

## 一、为什么要重做（实测结论）
- 用户要求：顶面 = 六边形格子尺寸，侧面超出格子范围。
- 代码已做 X/Y 分别标定（`solidBoardPlacement`），顶面已能精确填满格子（实机 `GEO-live-v1.png` 确认）。
- 但 OLD 素材的侧面在当前标定下视觉太弱：侧面像素虽是实心（alpha 203~255），纵向拉伸后被推到下一格位置，又被归属色描边/暗底压制，实机特写 `GEO-side-overflow.png` 里几乎看不见。
- 结论：顶面达标，侧面靠现有素材救不回来 → 重出一版侧面更厚更实的 hex_bright。

## 二、风格锚点（16 张铁律，本张严格遵守）
- **顶面完全不变**：以 `assets/tiles/hex_bright.png`（OLD 饱满石砖）为参考图，顶面圆润 pointy-top 六边形、青灰石纹细裂纹、L≈130、左上光、中央低细节——这些一个字都不改。
- **只改侧面**：厚度侧面（顶面下方的垂直壁）加厚、加深层次，青灰比顶面暗一档（L≈95–115），有明确侧壁宽度和明暗过渡；不要硬黑描边。
- **投影加强**：底部米白接地投影加宽加实，alpha 足够在深靛夜景底上清晰可见（当前投影 alpha 偏低）。
- 视角/光源/材质/尺寸：沿用 pointy-top 正俯视、左上光、哑光青灰、312×312 RGBA 透明底。

## 三、构图比例（关键，保证与标定对齐）
| 区域 | 当前图内 y 占比 | 重做目标 |
|---|---|---|
| 顶面六边形 | y 28..176（约 48% 高）| 不变，仍是顶面中心对齐格心的基准 |
| 厚度侧面 | y 176..250（约 24%）| **加厚到约 32–38%**，侧壁更宽更实 |
| 米白投影 | y 250..285（约 11%）| 加宽到约 14–16%，更明显 |

> 顶面位置与占比锁死，侧面/投影向下延伸——这样 `solidBoardPlacement` 的顶面标定无需再改，侧面自然溢出格子下缘。

## 四、生成与后处理路径
1. **图生图**：以 OLD 石砖为参考图，prompt 强调「顶面六边形造型/裂纹/颜色/光照完全不变，只把下方厚度侧面加厚、投影加强；新侧面与顶面共享光影/厚度/透视；其余不变」。高 input_fidelity。
2. **去背**：`tools/refine-old-tile.py`（凸包重建 + 连通域去噪 + 程序化投影）。注意：若新图投影已经是实心且干净，需调整脚本让它保留原投影而非完全程序化生成。
3. **规格**：LANCZOS 到 312×312、主体居中、alpha 校验（四角透明、顶面实心 255、无棋盘格噪点、无水印）。
4. **staging 审核**：产物落 `.workbuddy/art-staging/board-art/`，出拼版 + 实机截图给你确认，确认后才覆盖 `assets/`。
