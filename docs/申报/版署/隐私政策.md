# 《占地之王》隐私政策

> 版本：V1.0　｜　生效日期：以本游戏内实际公示为准
> 运营主体：**摩若游戏（广州）有限公司**（本政策中简称"运营方"或"我们"）

## 前言

运营方重视您的个人信息与隐私保护。本政策依据《中华人民共和国个人信息保护法》《中华人民共和国未成年人保护法》《中华人民共和国网络安全法》等法律法规，说明本游戏在个人信息处理方面的实际情况。

请您在使用本游戏前完整阅读本政策。如您不同意本政策，请停止使用本游戏。

**特别说明：当前版本为单机原型，不设账号体系，不收集您的任何个人信息。**

## 第一条　信息收集范围

1.1 当前版本，本游戏自身不收集您的个人信息，包括但不限于：手机号码、昵称、头像、真实姓名、身份证件号码、地理位置、通讯录、相册内容、设备唯一标识符等。

1.2 当前版本不设账号体系，您无需注册或登录即可使用本游戏，运营方无法通过本游戏识别您的身份。

1.3 本游戏当前不调用微信用户信息接口获取您的昵称、头像等资料，不使用微信支付、不接入第三方统计或数据分析 SDK。

1.4 请您理解：本游戏运行于微信客户端，微信平台可能基于其自身规则与隐私政策收集、处理您的部分信息（如设备与网络基础信息）。该等信息由腾讯公司按其规则处理，适用微信平台的隐私政策，而非本政策。

1.5 当前版本不存在向运营方服务器上传用户数据、用户行为日志或存档数据的行为。

## 第二条　本地存储说明

2.1 本游戏使用微信提供的本地存储能力（`wx.setStorageSync`）保存游戏进度与设置，数据量约为 100KB，全部存储在您所使用的设备本地。

2.2 上述本地存档不上传至运营方或任何第三方服务器，运营方不因该存档而获得您的个人信息。

2.3 您可以自行管理本地数据：清理微信缓存、删除本游戏、卸载微信或更换设备，均可能导致本地存档被清除且无法恢复，请谨慎操作。

2.4 本游戏不使用 Cookie、设备指纹或其他用于跨应用追踪您身份的技术。

## 第三条　第三方 SDK 与权限

3.1 当前版本，本游戏未接入用于收集个人信息的第三方 SDK，未接入广告 SDK（激励视频广告当前关闭）、未接入支付 SDK、未接入第三方数据分析或归因 SDK。

3.2 当前版本，本游戏不申请通讯录、相册、摄像头、麦克风、精确地理位置、蓝牙等敏感系统权限。未来如因新增功能确需申请上述权限，运营方将在使用前单独告知目的、方式和范围，并依法取得您的同意。

3.3 本游戏依赖微信客户端提供的基础运行环境与分发能力，相关数据处理适用微信平台规则。本游戏内如含第三方素材，其权利归属依相应授权约定处理，不涉及您个人信息的收集。

## 第四条　未成年人保护

4.1 运营方已提供并将持续完善未成年人保护机制，包括：在游戏内及宣传物料中提供适龄提示（建议评级 8+，最终以审定为准）、提供青少年模式开关、落实防沉迷时长与时段的前端管控、提供实名认证引导。

4.2 若后续接入实名认证与防沉迷系统，运营方将依照法律法规、监管要求及微信平台规则，对未成年人使用时长、使用时段及消费行为进行限制，并对未实名或身份验证不通过的账号采取相应措施。

4.3 若您为未成年人的监护人，对本游戏使用或未成年人个人信息保护事项有疑问，可通过本政策第八节所列方式联系运营方；运营方将依法予以处理。

4.4 运营方尊重并保护不满十四周岁未成年人的个人信息；涉及处理该年龄段未成年人个人信息的，将依法取得其父母或其他监护人的同意。

## 第五条　信息安全

5.1 当前版本由于不收集、不上传个人信息，运营方不存在持有您的个人信息因而发生泄露、篡改或丢失的风险；本地存档安全由您所使用的设备与微信客户端环境保障。

5.2 未来如依法收集个人信息，运营方将采取与其处理目的相匹配的安全措施，包括但不限于最小必要收集、访问权限控制、加密传输与存储、保存期限管理等，防止信息泄露、篡改或丢失。

5.3 除法律法规另有规定或经您单独同意外，运营方不会向任何第三方提供、公开或转让您的个人信息。发生法律法规规定的例外情形时，运营方将在法律允许的范围内说明情况。

5.4 发生或可能发生个人信息泄露等安全事件时，运营方将依法启动应急预案并采取补救措施，按规定履行通知与报告义务。

## 第六条　未来接入实名认证后的个人信息处理（预留条款）

6.1 为符合《中华人民共和国未成年人保护法》《关于进一步严格管理 切实防止未成年人沉迷网络游戏的通知》等规定，本游戏未来可能接入实名认证与防沉迷系统。届时的处理方式如下：

（1）**处理目的与方式**：核验用户真实身份、判断年龄，落实未成年人使用时长与时段限制、消费限制，并履行监管要求的实名信息登记与上报义务。

（2）**信息类型与范围**：可能包括真实姓名、身份证件号码等实名必需信息，以及为完成核验所必需的账号标识、登录与时长记录。运营方将遵循最小必要原则，只处理实现上述目的所必需的信息。

（3）**接入通道**：优先通过微信平台提供的官方实名认证与防沉迷对接通道，并接入国家新闻出版署防沉迷实名认证系统。相关信息由平台及主管部门按其规则与法律法规处理；如运营方需另行收集或处理，将依法告知并取得您的同意。

（4）**同意与撤回**：处理前将以清晰、易懂的方式告知目的、方式、范围与保存期限，并依法取得同意；涉及不满十四周岁未成年人的，将依法取得其父母或其他监护人的同意。您可依法撤回同意，但撤回不影响撤回前基于同意已进行的处理活动的效力。

（5）**保存期限**：实名与防沉迷相关记录按监管要求的最短必要期限保存，期限届满后依法删除或匿名化处理。

（6）**您的权利**：您可依法行使查阅、复制、更正、补充、删除个人信息以及要求解释说明等权利，可通过本政策第八节所列方式提出请求。如需撤回同意或注销相关账号（如届时已建立账号体系），运营方将按法律法规与平台规则办理。

6.2 上述内容为对未来功能的前瞻性说明，不代表当前版本已具备相关能力。正式接入前，运营方将据实更新本政策并重新公示，明确实际的信息处理者、处理范围与合规依据。

6.3 未来如开放内购、广告变现或其他涉及个人信息处理的功能，运营方将另行告知并依法履行相应的合规义务。

## 第七条　政策更新

7.1 因法律法规变化、监管要求、产品功能调整或接入新的第三方服务等原因，运营方可能修订本政策。

7.2 修订后的政策一经在本游戏内公示即生效。您在公示后继续使用本游戏的，视为接受修订后的政策；若您不接受，应停止使用本游戏。涉及个人信息处理目的、方式、范围等重大变更的，运营方将依法重新取得您的同意。

7.3 本政策与《用户协议》共同适用于本游戏，二者不一致的，就个人信息保护事项以本政策为准。
