# 未成年人保护与防沉迷系统 · 合规说明

> 用途：版署申报前置合规说明 + 整改任务书
> ⚠️ **重要（2026-11-21 更新）**：**前端层已落地**适龄提示 8+ 首次确认、实名引导入口、青少年模式开关、时长与时段本地管控（截图见 `screenshots/适龄提示8+.png`、`实名认证引导.png`、`防沉迷拦截.png`）；但**服务端实名核验与国家新闻出版署防沉迷系统尚未接入**，这仍是版号申报的一票否决项。本文区分「已实现」与「待接入」，不虚构能力。

---

## 1. 法规依据

| 法规 / 文件 | 核心要求 |
|---|---|
| 《中华人民共和国未成年人保护法》（2020 修订） | 网络产品和服务提供者应针对未成年人设置相应的时间管理、权限管理、消费管理等功能 |
| 《关于进一步严格管理 切实防止未成年人沉迷网络游戏的通知》（国新出发〔2021〕14 号） | 所有网络游戏用户必须使用真实有效身份信息注册；**仅可在周五、周六、周日及法定节假日 20:00—21:00 向未成年人提供 1 小时网络游戏服务**；其他时间一律不得提供 |
| 《网络游戏防沉迷实名认证系统接入指引》 | 游戏须接入国家新闻出版署防沉迷实名认证系统，完成实名注册、登录时长上报与消费限制 |
| 《网络游戏适龄提示》团体标准 | 在登录界面、官网等显著位置标注 8+ / 12+ / 16+ / 18+ 适龄提示 |
| 《关于规范网络游戏运营加强事中事后监管工作的通知》 | 需明示概率公示、限制未成年人充值 |

## 3. 整改任务清单

### 3.1 接入微信小游戏实名与防沉迷能力（P0）

微信小游戏平台已提供官方的实名认证与防沉迷对接能力，优先走平台通道而非自建：

- [ ] 在微信公众平台（mp.weixin.qq.com）完成小游戏主体认证与「游戏类目」资质提交；
- [ ] 开通微信小游戏的**实名认证能力**，在游戏启动时校验用户实名状态；
- [ ] 接入**国家新闻出版署防沉迷实名认证系统**（通过微信平台提供的对接通道），完成：
  - 登录时上报账号与实名信息；
  - 实时计算在线时长，达到 1 小时强制下线；
  - 仅周五/周六/周日及法定节假日 20:00—21:00 允许未成年人进入；
  - 每日 22:00—次日 8:00 禁止未成年人登录（平台规则叠加）；
- [ ] 实现未成年人**消费限额**：8 岁以上不满 16 岁单次≤50 元、月累计≤200 元；16 岁以上不满 18 岁单次≤100 元、月累计≤400 元（若后续开放内购）；
- [ ] 保存实名/防沉迷校验日志，供监管抽查。

**验收标准**：使用未实名账号、未成年人账号、成年人账号分别实测，时长限制与时段拦截均生效，且有明确的提示文案与强制下线界面。

### 3.2 适配微信青少年模式（P0）

- [ ] 检测微信青少年模式状态，命中时按平台限制执行（时长、时段、内容）；
- [ ] 青少年模式下隐藏或禁用招募、商店等可能涉及消费的入口；
- [ ] 遵循平台对青少年模式的 UI 提示规范。

### 3.3 配置适龄提示（P1）

- [ ] 按《网络游戏适龄提示》团体标准自评，建议本游戏评为 **8+**（架空奇幻、Q 版卡通、无血腥暴力、无赌博）；
- [ ] 在**启动加载页**与**大厅界面**显著位置展示适龄提示标识；
- [ ] 在微信小游戏详情页、官方宣传物料同步标注；
- [ ] 最终评级以出版单位与主管部门审定为准。

### 3.4 补充隐私与用户协议（P1）

- [ ] 游戏内提供《用户协议》《隐私政策》入口（即使不收集个人信息也须公示）；
- [ ] 说明本地存档机制、数据不上传、无第三方 SDK 采集；
- [ ] 说明未成年人保护规则与监护人联系方式。

### 3.5 付费功能前置约束（P1）

当前内购、广告均关闭。若后续开放：

- [ ] 接入实名与消费限额后方可开启；
- [ ] 招募/抽奖概率公示持续保留，且公示内容与实际概率一致；
- [ ] 未成年人消费退款通道与客服渠道就绪。

## 4. 建议实现位置（工程指引）

以下为改造入口建议，供开发排期参考，非当前实现：

| 能力 | 建议接入点 | 说明 |
|---|---|---|
| 启动校验 | `game.js` 启动流程，`wx.loadSubpackage` 之前 | 未实名/未成年违规时段直接拦截，不进入游戏 |
| 时长计时 | `src/game/Game.js` 主循环 `tick` | 累计在线时长，1 小时到点弹窗并冻结输入 |
| 时段拦截 | `src/game/Game.js` 启动与恢复前台时 | 读取当前星期与时刻，非允许时段拒绝进入 |
| 青少年模式 | `game.js` 入口 + `src/game/Game.js` | 按微信 API 返回值隐藏相关入口 |
| 适龄提示 | `src/game/Game.js:renderLoadingScreen`、大厅渲染 | 绘制 8+ 标识，位置固定且不被遮挡 |
| 协议入口 | 大厅设置界面 | 增加《用户协议》《隐私政策》两个入口 |

- [ ] 实名认证接入完成，有微信平台侧开通证明截图；
- [ ] 防沉迷系统联调通过，时长/时段限制实测生效；
- [ ] 适龄提示标识在游戏内与宣传物料均已展示；
- [ ] 青少年模式适配完成并实测；
- [ ] 用户协议与隐私政策已公示；
- [ ] 形成《防沉迷系统接入说明》正式盖章文件，随版号材料提交。

> 上述任何一项未完成，都不建议提交版号申请——形式审查阶段即会被退回，且留下不良申报记录。
