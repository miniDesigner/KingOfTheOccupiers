# 《占地之王》游戏内容与玩法说明

> 用途：版署申报「游戏内容介绍 / 脚本」附件
> 说明：本文据工程实际实现编写，覆盖世界观、玩法规则、界面、文本与美术内容，供审查员了解游戏全貌。

---

## 1. 游戏概述

《占地之王》是一款架空奇幻题材的六边形策略战棋游戏，运行于微信小游戏平台。玩家作为一方势力首领，在有限的六边形棋盘上通过探索、经营与军事调度扩张领地，最终摧毁敌方大本营获胜。单局时长约 30～50 秒，节奏明快，属于轻度策略品类。

游戏**不含剧情主线、不含角色对白、不含聊天与社区功能、不含玩家间实时对抗**，全部对手为 AI。

## 2. 世界观与题材设定

- **时代背景**：架空的奇幻大陆，无对应现实历史时期、国家、民族或宗教；
- **势力设定**：玩家与 AI 分别代表不同颜色的抽象势力（蓝方为玩家、红方为敌方），以领地争夺为核心冲突；
- **角色设定**：兵种为 Q 版幻想生物（战士、弓手、法师等）与奇幻建筑（兵营、箭塔、金矿、主城），无现实人物原型；
- **价值导向**：强调经营规划与策略决策，无暴力美化、无阵营对立现实映射。

> 合规要点：全部内容为架空设定，不涉及现实政治、历史人物、民族宗教、地缘争议；不含血腥、色情、赌博、毒品、迷信内容。

## 3. 核心玩法规则

### 3.1 棋盘与地形

- 棋盘为 **11×7 共 77 格**六边形网格，采用轴向坐标 (q, r)；
- 地形包含平原、矿产、障碍等 5 套布局；
- 部分格子初始处于未翻状态，需花费金币翻开后才可使用；
- 未翻格中的建筑以剪影预告类型，翻开后显示完整图标。

### 3.2 资源与经营

| 资源 | 获取方式 | 用途 |
|---|---|---|
| 金币 | 每秒被动产出 + 金矿产出 + 击杀赏金 | 翻格、建造、升级 |
| 星尘 | 任务、结算奖励 | 局外科技升级、招募 |

- 双方初始金币均为 200，规则对称；
- 兵营随时间自动生产战士，累积至 9 名自动编队出发。

### 3.3 建筑系统

| 建筑 | 功能 |
|---|---|
| 兵营 | 周期性生产战士 |
| 箭塔 | 自动攻击经过的敌方队伍 |
| 金矿 | 提升金币产出 |
| 大本营 | 核心建筑，被摧毁即判负 |

建筑可升级，等级越高产出/防御越强。

### 3.4 兵种与战斗

- 兵种分 6 档品质（白/绿/蓝/紫/橙/红），品质差异主要体现在技能解锁、羁绊与射程，战力倍率压缩在 1.0～1.18 之间；
- 战斗采用确定性结算：队伍战力对比目标防御，按五档阈值判定伤害；远程兵种先手削减目标 30～60% 兵力；
- 攻城为持续磨血机制，每次交战按固定间隔结算，近战攻城失败会全灭队伍；
- 兵种之间存在羁绊组合，激活后提供属性加成。

### 3.5 胜负判定

- 摧毁敌方大本营 → 胜利；己方大本营被摧毁 → 失败；
- 结算界面展示胜负、战绩与奖励；胜利时可分享战绩（微信系统分享能力）。

### 3.6 AI 行为

AI 对手按难度分 4 档（easy / normal / hard / nightmare），决策间隔 3.8 / 2.6 / 2.2 / 1.95 秒。AI 依据当前资源与局势自主决定翻格、建造、升级与出兵，无作弊资源，与玩家使用同一套规则与数值。

## 4. 局外养成系统

| 系统 | 内容 | 是否涉及付费 |
|---|---|---|
| 兵种招募 | 图鉴查看、单抽/十连、概率公示与保底 | 否（消耗游戏内星尘） |
| 商店 | 免费领取、星尘兑换、训练物资、特惠 | 否（当前版本无人民币购买渠道） |
| 科技树 | 4 分支多节点，消耗星尘升级 | 否 |
| 装备 | 装备穿戴与强化 | 否 |
| 任务 / 成就 | 每日任务与成长成就，奖励领取 | 否 |
| 通行证 | 赛季奖励（当前版本关闭） | 否 |
| 排行榜 | 4 类榜单展示本地数据 | 否 |
| 设置 | 音效/BGM 开关 | 否 |

## 5. 界面清单

游戏共包含 15 个界面/状态，均可从游戏主流程到达：

| # | 界面 | 标识 | 说明 |
|---|---|---|---|
| 1 | 启动加载页 | — | 展示游戏名称与加载进度 |
| 2 | 大厅 | `lobby` | 资源栏、玩家卡、功能入口、开战 |
| 3 | 布阵 | `deploy_select` | 上阵、羁绊、强化、兵库 |
| 4 | 兵种详情 | `unit_detail` | 属性、技能、羁绊 |
| 5 | 招募 | `gacha` | 概率、保底、单抽/十连 |
| 6 | 商店 | `shop` | 分页商品列表 |
| 7 | 科技 | `tech_panel` | 4 分支科技树 |
| 8 | 通行证 | `battle_pass` | 赛季奖励（默认关闭） |
| 9 | 任务 | `quest` | 每日与成长任务 |
| 10 | 成就 | `achievement` | 成就进度 |
| 11 | 排行榜 | `leaderboard` | 4 类榜单 |
| 12 | 设置 | `settings` | 音效/BGM |
| 13 | 账号 | `account` | 本地存档信息 |
| 14 | 战斗 | `playing` | 棋盘与 HUD |
| 15 | 结算 | `gameOver` | 胜负结果、战绩、分享 |

## 6. 游戏文本一览

游戏内文本均为功能性短文案，无剧情对白。主要文案示例：

| 类别 | 文案示例 |
|---|---|
| 界面标题 | 占地之王、布阵、招募、商店、科技、任务、成就、排行榜、设置 |
| 操作按钮 | 开战、返回大厅、炫耀战绩、一键领取、单抽、十连、升级、领取 |
| 状态提示 |  victories / 失败、可升级、未解锁、已领取、今日次数已用完、需看完广告才能领取 |
| 资源名称 | 金币、星尘、钻石、训练物资 |
| 建筑名称 | 兵营、箭塔、金矿、大本营 |
| 品质名称 | 普通、良好、优秀、史诗、传说、神话 |
| 难度名称 | 轻松、普通、困难、噩梦 |

> 合规要点：全部文本为中性游戏术语，无违规词汇、无现实人物/机构名称、无诱导性表述。完整文本以运行时资源为准。

## 7. 美术与音频内容

- **美术风格**：Q 版厚涂卡通，圆润无硬描边、糖果高光，界面主调为「晴空乐园」（天蓝 #5BB8E8 / 云白 #EAF8FF / 明黄 #FFD23F / 活力橙 #FF8C42）；
- **素材构成**：兵种立绘、建筑图标、界面九宫格、地块贴图、特效等，共 331 项登记素材；
- **音频**：17 个音效 + 1 首 BGM（当前为占位音源，正式版需替换为已授权素材）；
- **字体**：标题与数字使用自定义字体文件 `fonts/title.ttf`、`fonts/number.ttf`（**字体来源与授权待确认**，见自审报告）；
- **内容合规**：不含血腥、裸露、暴力细节、现实标志、赌博元素；败北表现仅为建筑消失与界面变灰。

## 8. 数据与安全

- 不收集用户手机号、身份证号、位置、通讯录等任何个人信息；
- 不包含用户生成内容（UGC），无聊天/评论/弹幕功能，不存在内容审核风险；
- 无外部链接跳转、无第三方 SDK 数据采集；
- 对局逻辑全部本地运行，确定性 RNG 保证结果可复现。
