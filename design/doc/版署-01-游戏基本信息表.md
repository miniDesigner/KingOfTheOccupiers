## 三、玩法与内容摘要（申报表简述栏可用）

> 以下文字约 250 字，可直接用于申报表「游戏内容简述」。

```
《占地之王》是一款架空奇幻题材的六边形策略战棋游戏。玩家在 11×7 的六边形棋盘上
经营领地、翻格探索、建造兵营与箭塔、生产兵种并编队行军，通过与 AI 对手争夺地块、
摧毁敌方大本营取得胜利。游戏包含大厅、布阵、招募、商店、科技、任务、成就、
排行榜与战斗结算等界面，局外提供兵种收集、科技升级、装备强化与每日任务等长线养成。

游戏无剧情对白、无聊天系统、无用户生成内容、无玩家间实时交互；画面为 Q 版卡通
风格，不含血腥暴力、色情、赌博及现实政治历史内容。当前版本为单机 PvE 原型，
不开放内购与广告变现，不含社交分享以外的任何联网功能。
```

## 四、付费与商业化现状

| 项目 | 当前版本状态 | 说明 |
|---|---|---|
| 内购充值 | **关闭** | 配置 `features.shopDiamondTab=false`，钻石充值分页完全隐藏 |
| 赛季通行证付费 | **关闭** | 配置 `features.battlePass=false`，入口与商品均隐藏 |
| 激励视频广告 | **关闭** | `config/ads.json` 中广告位 ID 为占位值，`enabled=false` |
| 虚拟货币 | 游戏内产出（金币、星尘） | 仅通过玩法获得，无人民币购买渠道 |
| 付费转化入口 | 无 | 当前版本不存在任何人民币支付行为 |

> **合规提示**：版号获批后若计划开放内购/广告，须先按监管要求完成实名认证与防沉迷系统接入，并对付费限额做未成年人保护限制。详见 `版署-03-防沉迷与实名合规说明.md`。
