## 4. 截图制作规范

1. **分辨率**：430×932 基准尺寸（与项目设计基准一致），或按出版单位要求提供；
2. **正式素材**：将 `config/game.json` 的 `features.artAlpha` 从 `0.5` 改为 `1`，并确认所有占位图已替换为正式图；
3. **无水印**：不得出现素材水印、调试文字、控制台信息；
4. **无调试 UI**：不显示 FPS、坐标、命中框等开发辅助信息；
5. **中文清晰**：字体加载正常，无乱码、无方块字；
6. **保存格式**：PNG（截图）或 JPG（体积受限时），文件名用中文注明内容。
