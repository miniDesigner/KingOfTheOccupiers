## 三、软件用途与技术特点（申请表文本栏）

> 以下文字可直接粘贴进申请表「软件的主要功能和技术特点」栏（约 300 字，如字数超限自行删减）。

```
《占地之王》是一款基于微信小游戏平台开发的六边形策略战棋游戏。玩家在 11×7 的
六边形棋盘上通过翻格、建造、产兵与行军扩张势力，与 AI 对手争夺地块，摧毁对方
大本营即获胜。软件包含大厅、布阵、招募、商店、科技、任务、通行证、排行榜、
战斗 HUD 与结算等界面，以及局外养成与存档系统。

技术特点：①采用六边形轴向坐标 (q,r) 与 A* 寻路算法实现网格推演；②基于 Canvas 2D
与 requestAnimationFrame 构建双缓冲渲染主循环，渲染与点击命中共用同一套布局函数，
保证多分辨率下坐标一致；③使用 Mulberry32 确定性种子随机数，使同一对局可复现，
便于平衡性回归测试；④配置与代码分离，16 组 JSON 配置经构建脚本编译为小游戏可
加载的 JS 模块；⑤适配微信安全区、分包加载与 Canvas 字体，主包体积控制在 4MB 以内；
⑥内置 73 项自动化回归测试，覆盖玩法逻辑、界面布局、入口适配与微信环境兼容。
软件无第三方运行时依赖，可在微信小游戏容器及现代浏览器中运行。
```

## 六、易踩的坑

1. **开发完成日期不能晚于首次发表日期**，也不能填未来日期。
2. 软件全称一旦登记即成为证书上的正式名称，**须与版署申报的游戏名称一致**，否则后续要额外做名称变更证明。
3. 源码文档里**不要留大段注释或空行充数**，审查员会按有效代码行判定；不要提交带水印的占位素材截图。
4. 若软件中使用了第三方字体/音乐/图片，软著登记本身不要求授权证明，但**版署自审会查**，见 `版署-04-游戏自审报告.md`。
