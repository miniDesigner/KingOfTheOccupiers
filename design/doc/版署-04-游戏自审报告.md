# 《占地之王》游戏内容自审报告

> 用途：版署申报随附的出版单位/运营单位自审材料
> 说明：本报告依据工程实际内容逐项自查。**标注 🟠/🔴 的项目为待整改项，须在提交前闭环**。自审结论需由出版单位复核并盖章。
> 更新（2026-11-21）：P0 的前端层已落地——适龄提示 8+、青少年模式开关、时长/时段本地管控、实名引导入口；加载页已常驻展示健康游戏忠告标准文案（标题 + 四句，深色底板保证清晰）。下文 🔴 项以**服务端实名核验仍未接入**为准。

## 1. 自审依据

- 《出版管理条例》《网络游戏管理暂行办法》相关规定
- 《关于移动游戏出版服务管理的通知》（新广出办发〔2016〕44 号）
- 《网络出版服务管理规定》
- 《关于进一步严格管理 切实防止未成年人沉迷网络游戏的通知》（国新出发〔2021〕14 号）
- 《网络游戏适龄提示》团体标准
- 《移动游戏内容规范（2016 年版）》及出版单位内容审读要求

## 2. 自审范围

本次自审覆盖游戏名称、世界观、剧情文本、界面文案、角色与场景美术、音频、玩法机制、付费设计、未成年人保护、知识产权与数据安全，共 10 个维度。自审对象为《占地之王》V1.0 微信小游戏版本。

## 3. 逐项自审结论

### 3.1 游戏名称与题材 🟢

| 检查项 | 结论 |
|---|---|
| 名称是否含违规字词 | 通过。「占地之王」为中性策略表述，无夸大、迷信、暴力诱导 |
| 题材是否涉及现实政治/历史 | 通过。架空奇幻设定，无现实国家、民族、宗教对应 |
| 是否易引发歧义或不良联想 | 通过 |

### 3.2 世界观与价值导向 🟢

- 无歪曲历史、损害国家主权和领土完整的内容；
- 无宣扬暴力、恐怖、极端主义的内容；
- 无封建迷信、伪科学内容；
- 玩法强调经营规划与策略决策，价值导向积极；
- 阵营冲突为抽象颜色对抗（蓝方/红方），不映射现实群体。

**结论**：通过。

### 3.3 美术内容 🟠（待闭环）

| 检查项 | 结论 |
|---|---|
| 血腥暴力表现 | 通过。Q 版卡通，无血液、肢体、伤口表现；单位消失为粒子效果 |
| 色情低俗内容 | 通过。角色造型保守，无暴露、挑逗性设计 |
| 现实标志/人物 | 通过。全部为原创幻想生物与建筑 |
| 赌博元素 | 通过。无老虎机、赌场等表现 |
| **素材来源与授权** | 🟠 **待确认**：当前 331 项素材中大部分为占位图，正式素材替换中；须逐一确认版权归属或取得授权 |
| **字体授权** | 🟠 **待确认**：`fonts/title.ttf`、`fonts/number.ttf` 须确认可商用授权， Otherwise 替换为开源字体（如思源黑体） |
| **音频授权** | 🟠 **待确认**：17 个音效 + 1 首 BGM 当前为占位音源，须替换为已授权素材 |

**整改要求**：提交前完成素材/字体/音频的版权确认，留存授权凭证或采购记录；《软著证书》与素材版权链保持一致。

### 3.4 文本与剧情内容 🟢

- 无剧情对白、无旁白、无歌词；
- 界面文案均为功能性术语（开战、升级、领取等），无违规词汇；
- 无用户生成内容（UGC），无聊天/评论/弹幕功能，不存在内容审核风险；
- 无现实人物、机构、品牌名称。

**结论**：通过。

### 3.5 玩法机制 🟢

| 检查项 | 结论 |
|---|---|
| 是否含赌博机制 | 通过。招募虽有随机性，但为游戏内星尘消耗、无人民币兑换、无实物奖励，且已公示概率与保底 |
| 是否诱导过度消费 | 通过。当前版本无任何付费入口 |
| 是否含暴力奖惩 | 通过。战败仅表现为界面提示与建筑消失，无虐待、羞辱性设计 |
| 是否存在成瘾性设计 | 🟡 轻度关注。单局 30～50 秒、节奏明快，须配合防沉迷系统限制时长（见 3.8） |

**结论**：基本通过，成瘾性风险由防沉迷系统对冲。

### 3.6 付费与消费保护 🟢

- 当前版本内购（钻石充值）、赛季通行证付费、激励视频广告**全部关闭**；
- 无人民币支付渠道、无第三方支付 SDK；
- 游戏内货币仅通过玩法产出，不存在变相充值；
- 招募概率与保底规则已在界面明示。

**结论**：通过。若后续开放付费，须重新自审并补齐未成年人消费限制。

### 3.7 数据安全与隐私保护 🟡（待闭环）

| 检查项 | 结论 |
|---|---|
| 是否收集个人信息 | 通过。不收集手机号、身份证号、位置、通讯录等 |
| 是否上传用户数据 | 通过。无服务器、无数据上报，纯本地存档 |
| 是否含第三方 SDK 采集 | 通过。零第三方运行时 SDK |
| 隐私政策公示 | 🟡 **待补充**：虽不收集信息，仍须在游戏内公示《隐私政策》与《用户协议》 |

**整改要求**：补充隐私政策入口与文本，说明本地存档机制与数据不上传。

### 3.8 未成年人保护 🔴（一票否决项）

| 适龄提示标识 | 🟠 加载页 8+ 提示卡与首次确认已实现，大厅标识与宣传物料待同步 |

| 健康游戏忠告 | 🟢 已实现：加载页常驻展示标准文案（标题 + 四句），深色底板保证在明亮插画上清晰可辨 |

**整改要求**：剩余一票否决项为**服务端实名核验**，这是版号申报的硬性前置条件，**必须在提交前完成**。详细整改清单与验收标准见 `版署-03-防沉迷与实名合规说明.md`。未完成前不得提交申报。

### 3.9 知识产权 🟠（待闭环）

### 3.10 运营与网络安全 🟢

- 无外部链接跳转、无第三方广告跳转；
- 无用户间交互、无社交分享内容生成（仅微信系统分享游戏链接）；
- 无在线客服/客服系统，无内容审核义务；
- 无服务器，不存在数据泄露与网络攻击面。

**结论**：通过。

### 总体结论

游戏内容本身符合出版规范，无违规内容。**但存在三类阻塞项：**

1. 🔴 实名认证与防沉迷系统未接入（一票否决）；
2. 🟠 美术/字体/音频素材的版权归属待确认；
3. 🟡 软件著作权证书待取得。

完成上述整改并经出版单位复核后，方可提交版号申请。
