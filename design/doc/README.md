## 2. 申报顺序

```
① 软著登记（30~60 天）
   └── 用「软著-01/02/03」+ 源码 HTML
   ↓（可与 ② 并行）
② 实名认证 + 防沉迷改造（见「版署-03」）
   └── 这是版号的一票否决项，必须完成
   ↓
③ 正式素材替换 → 按「screenshots/截图清单.md」截图录视频
   ↓
④ 出版单位签约、内容审读
   ↓
⑤ 版号申报（用「版署-01~05」全套）
```

**关键路径**：软著办理与实名防沉迷改造应**并行启动**，不要串行等待。

> 📌 **要派活时直接看** `版署/版署-04-游戏自审报告.md` 的 **§5 待处理内容清单**——15 条行动项按 P0（一票否决）/ P1（实质风险）/ P2（补充说明）分级，每条含责任方、具体动作、验收口径与关联文档，并附处理顺序与提交前闭环检查表。本节（README §3/§4）只是它的摘要。

## 5. 使用约定

1. 所有 `【待填】` 标记须在正式提交前替换，不要留空提交；
2. 本目录文档为 Markdown 底稿，交付出版单位/主管部门时按对方要求转为 Word/PDF 并盖章；
3. 源码 HTML 可直接用 **Microsoft Word 打开**，另存为 `.docx` 或 PDF 后提交；
4. 工程代码或素材变更后，重新运行源码生成脚本，确保登记版本与实际代码一致；
5. 本目录位于 `design/` 下，已被微信上传配置排除，**不会影响小游戏包体**。
